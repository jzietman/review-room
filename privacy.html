Privacy policy

Beit David review room is a personal tool. Only its owner authorizes it with Google, and only for the owner's own account.

What it accesses

  • Google Drive (drive.file): only files and folders this app creates. It creates one backup folder and saves review reports and encrypted backups there. It cannot see the rest of the Drive.
  • Google Sheets (spreadsheets): used to write the review's progress report to the one spreadsheet the owner configured.

How data is handled

  • The authorization is stored only on the owner's own server, readable only by the owner's account.
  • Google data is not sold, shared with anyone, used for advertising, or used to train AI models.
  • This page has no cookies or analytics of its own; it is hosted by GitHub Pages.

Removing access

The owner can revoke access at any time at myaccount.google.com/connections.

Questions: use the support address shown on the app's Google consent screen.
